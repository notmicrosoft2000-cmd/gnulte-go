The Unplugged programme

A series of small, independently shippable increments: replace every helper-binary shell-out with in-Go code so the toolkit runs on a bare box. tc and iptables stay. They are the kernel interface.

GNULTE

GNU LAN Network Testing Environment. Eight single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
