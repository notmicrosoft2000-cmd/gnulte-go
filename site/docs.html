Documentation

Applies to GNULTE v16.13 · last updated 2026-10-15

The manual is organised the way the toolkit is used: get it installed, configure the defaults once, run the tools, and look up individual commands as needed. Every command reference page lists the tool's flags as of the current release, with real examples.

Conventions

Flags
Shown as --long-name VALUE or -l VALUE. Go's flag parser accepts both -flag and --flag for every option. Command references are written against v16.13; run <tool> -h if you are running a different version.
Examples
Addresses such as 192.168.1.0/24 stand for your own subnet. Replace them with the network you are authorised to test.
Root
Tools that shape, spoof, inject or capture say so on their reference page. Every tool works unprivileged where that is technically possible.
Also in the repository: README.md (release notes for the Go edition), docs/V17-PLAN.md (the Unplugged development plan) and the safety documents printed by gnulte --docs.
