Conventions

flags
--long-name VALUE or -l VALUE. Go's flag parser accepts both forms.
versions
References are written against v17.0. Run <tool> -h if you are on another version.
addresses
Addresses such as 192.168.1.0/24 stand for your own subnet. Replace them with a network you are authorised to test.
root
Tools that shape, spoof, inject or capture say so on their reference page. Everything works unprivileged where technically possible.

GNULTE

GNU LAN Network Testing Environment. Eight Linux executables, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
