gnulte-devices(8) — instant inventory

Applies to gnulte-devices v16.13 · last updated 2026-10-15

The kernel's ARP/neighbour table turned into a full device list in one pass: vendor from the embedded OUI registry, mDNS hostnames, a device-type guess. No sweeps unless you ask, no root at all.

Requirements

  • No privileges needed.
  • By default reads the neighbour table only; -s adds a ping sweep, which works better with root.

Synopsis

gnulte-devices [flags]

Options

FlagDescription
-salso ping-sweep the subnet (default: ARP table only)
-t Nparallel ping workers when scanning
-i IFACEnetwork interface (default: auto-detect)
-nskip hostname resolution (fast)
-coutput CSV
-joutput JSON
-youtput YAML
-o FILEwrite the table to a file
-H FILEwrite an HTML report to this file
--oui-file FILEmerge an operator CSV vendor table (prefix,vendor) over the built-in OUI data
-qquiet: no banner, no status lines
-v, --versionprint version and exit

Long aliases exist for every short flag (--csv, --json, --yaml, --html FILE, --output FILE, --scan, --no-hostnames, --interface IFACE, --quiet).

Examples

gnulte-devices                # instant inventory from the neighbour table
gnulte-devices -s             # add a ping sweep of the subnet
gnulte-devices -s -H lan.html # inventory plus a filed HTML report
gnulte-devices -j -q          # just the JSON, nothing else

Installation

Part of the GNULTE suite. Build and install everything at once;

git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds all eight binaries, runs go vet + go test ./...
sudo ./install.sh   # installs to /usr/local/bin + safety docs

installs gnulte-devices to /usr/local/bin/gnulte-devices. See installation for requirements.

Common errors

The table is nearly empty
The neighbour table is only a cache. Add -s to ping-sweep the subnet first.
Resolving names is slow
Skip it with -n for a fast, address-only inventory.
