Synopsis

command
gnulte-hub
gnulte-hub --version

Description

gnulte-hub is the front door for the toolkit. It draws a numbered menu, then runs the selected binary in the same terminal. It does no network work itself and needs no privileges; each child asks for root only when the operation needs it.

The launcher looks for a binary in the directory that contains gnulte-hub first, then falls back to PATH. A directory copied to a USB stick therefore works without changing the environment. Tools that are not found are marked not installed in the menu.

Usage

terminal
gnulte-hub              open the menu
gnulte-hub --version    print version and exit
gnulte-hub -v           same as --version

Pick a row with the arrow keys or its number. After a child exits, press Enter to return to the menu. q or the Quit row leaves the launcher.

Rows 1–7 first ask for Standard or Detailed controls. Detailed adds launch-only session controls for beeps, ping interval and command echo; it never writes the settings file. Test a connection then asks what you want to do and offers four presets or exact numbers. Choosing exact numbers asks for latency, jitter, loss, duplication, reorder, bandwidth and duration in the launcher, then passes them to gnulte with --from-hub so the numeric wizard is not shown twice. Presets pass --profile instead. Target selection, the root handshake and all safety checks still happen inside gnulte.

Menu actions

RowRuns
Test a connectiongnulte
Check this machinegnulte-quicksum
Find devicesgnulte-scan
See connected devicesgnulte-inventory
Watch live trafficgnulte-watch
Wi-Fi toolsgnulte-wifi
Open reportsgnulte-report
Read the safety rulesgnulte --docs

Exit status

0
Normal exit, including --version and a clean Quit.
130
Interrupt or terminate signal. The launcher restores the screen and exits.

If a child exits with a non-zero status, the launcher prints that status and waits for Enter before returning to the menu.

Files

gnulte-hub reads one saved preference, hub_detailed, and writes no state. The choice persists only when you save it in settings. The binaries it launches use the paths in Where things live.
