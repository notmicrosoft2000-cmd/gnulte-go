Work with the reports the other tools save. It lists and indexes the report hub, merges device exports from different tools or days, diffs two exports, and files reports into dated folders. It reads local files only, so it needs no root and no network.

Requirements

  • No privileges and no helper binaries.
  • Added in v17.0.

Synopsis

command / output
gnulte-report <subcommand> [flags]

Subcommands

CommandDescription
list [DIR ...]show every auto-named report in the hub, or in the directories you pass, newest first
index [-o FILE] [DIR ...]write a self-contained HTML page grouping those reports by tool
merge [-o FILE] FILE ...fold several -j / --json device exports into one snapshot
compare [-html FILE] A Bdiff two device exports and print what changed
archive [-dest DIR] FILE ...copy reports into YYYY/MM folders under the destination root

How merge combines snapshots

Later files win for every field they set; earlier files fill the blanks they leave. Banner lists are combined in order without duplicates. The merged output is a bare JSON array, the same format the -j exports use, so it can be fed straight into gnulte --compare or merged again later.

Options

FlagDescription
-o FILEwrite the index or merged snapshot to a file instead of stdout
-html FILEwrite the comparison as an HTML report
-dest DIRarchive root; by default the archive folder inside the report hub
-v, --versionprint version and exit

Examples

command / output
gnulte-report list
gnulte-report index -o ~/index.html
gnulte-report merge before.json after.json -o all.json
gnulte-report compare before.json after.json
gnulte-report compare -html diff.html before.json,after.json
gnulte-report archive ./gnulte-scan-report-*.html

Installation

Part of the GNULTE suite. Build and install everything at once;

command / output
git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds all seven binaries, runs go vet + go test on the Go packages
sudo ./install.sh   # installs to /usr/local/bin + safety docs

installs gnulte-report to /usr/local/bin/gnulte-report. See installation for requirements.

Common errors

No reports found
The hub is empty or the directory was wrong. Pass a directory explicitly with list or index.
merge needs at least one snapshot file
Give one or more -j exports. A file that is not valid JSON is rejected with its path.
compare needs two snapshot files
Pass A.json B.json, or A.json,B.json as a single argument.

Related tools

  • gnulte — --compare A B runs the same snapshot diff
  • gnulte-scan — a -j export is one input to merge and compare
