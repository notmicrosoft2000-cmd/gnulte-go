gnulte-top(8) — the bandwidth top

Applies to gnulte-top v16.13 · last updated 2026-10-15

A live per-host and per-conversation bandwidth view built on the same in-process AF_PACKET counter the LAN watch uses: hosts ranked into a top-talker table with ↓/↑ rates, peer counts and bars. No iptables, no top(1), no iftop — just the counter. Added in v16.11.

Requirements

  • Root — the in-process AF_PACKET counter needs a capture socket.
  • No external tools; tcpdump and iptables are not involved.

Synopsis

sudo gnulte-top [flags]

Options

FlagDescription
-i SECONDSsampling interval in seconds
-n Nnumber of intervals to sample (0 = until quit)
-flowsshow conversations instead of hosts
-host TEXTonly show hosts whose address contains this text
-iface IFACEinterface to watch (default: the default-route interface)
-csvprint one sample as CSV and exit
-jsonprint one sample as JSON and exit
-qquiet: no banner
-vprint version and exit

Examples

sudo gnulte-top                         # live top talkers
sudo gnulte-top -flows                  # per-conversation instead of per-host
sudo gnulte-top -host 192.168.1.50 -n 10   # one host, ten intervals, then exit
sudo gnulte-top -json | jq .            # one machine-readable sample

Installation

Part of the GNULTE suite. Build and install everything at once;

git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds all eight binaries, runs go vet + go test ./...
sudo ./install.sh   # installs to /usr/local/bin + safety docs

installs gnulte-top to /usr/local/bin/gnulte-top. See installation for requirements.

Common errors

The table stays empty
The AF_PACKET counter needs a capture socket — run with sudo, and check -iface against the interface carrying the traffic.
Only one host appears
In switched networks you only see traffic that reaches your interface; put the host in the path (for example with gnulte) to account for its traffic.

Related tools

  • gnulte — run the top alongside a shaping session to see the effect on throughput
