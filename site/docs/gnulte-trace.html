gnulte-trace(8) — the path probe

Applies to gnulte-trace v16.13 · last updated 2026-10-15

An mtr-style hop-by-hop path probe with no traceroute(8) behind it: ICMP echo is built, checksummed and matched in-process at every TTL, and the time exceeded / destination-unreachable errors routers send back are decoded into hops. A live table runs while it probes; a finished table is left in the scrollback.

Requirements

  • Root — raw ICMP sockets are required. Added in v16.10.
  • Routers along the path may rate-limit their ICMP replies; that shows up as per-hop loss, which is part of the measurement rather than an error.

Synopsis

sudo gnulte-trace [flags] HOST

Options

FlagDescription
-c Nprobes per hop
-i MSpause between the probes of a hop, in milliseconds
-t MSper-probe timeout in milliseconds
-m Nmaximum number of hops
-jsonprint the result as JSON
-html FILEalso write a self-contained HTML report to FILE
-qquiet: no live view, print the final table only
-vprint version and exit

Examples

sudo gnulte-trace 1.1.1.1                        # live hop-by-hop table
sudo gnulte-trace -m 20 -c 10 192.168.1.1        # bounded hops, more probes per hop
sudo gnulte-trace -q -json 1.1.1.1 | jq .        # just the data
sudo gnulte-trace -html trace.html 1.1.1.1       # file a report of the path

Output

Per hop: the responding address, and last / avg / best / worst round-trip times with the loss seen at that hop. Compare a trace taken under gnulte shaping with a clean one to see exactly where the impairment lands.

Installation

Part of the GNULTE suite. Build and install everything at once;

git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds all eight binaries, runs go vet + go test ./...
sudo ./install.sh   # installs to /usr/local/bin + safety docs

installs gnulte-trace to /usr/local/bin/gnulte-trace. See installation for requirements.

Common errors

Every hop shows *
The probe needs root for raw ICMP sockets. If only some hops are starred, those routers are rate-limiting ICMP replies.
The trace stops early
Raise the hop limit with -m; paths longer than the default are common on mobile and satellite links.
