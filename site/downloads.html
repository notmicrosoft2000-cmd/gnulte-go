Applies to GNULTE v16.13 · last updated 2026-10-15

GNULTE is distributed as source code only. There are no pre-built binaries and no binary mirrors: you clone or download the tree and build it with the Go toolchain, which takes under a minute and keeps the version you run in step with the repository.

Checksums and signatures. No binaries are published, so there are no binary checksums or GPG signatures to verify. To confirm the source you have is authentic, check the commit hash in the commit log against the tag on GitHub, and read the code — it is the whole point of the licence.

Build and install

Requirements: Go 1.21 or newer, Linux, and for shaping iproute2, iptables and iputils. No third-party Go modules are used.

git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds all eight binaries, runs go vet + go test ./...
sudo ./install.sh   # installs to /usr/local/bin + safety docs

Update with git pull && sudo ./install.sh — the installer reads the version from the freshly built binaries and aborts if they disagree, so an install can never drift behind the source tree. Uninstall with sudo ./uninstall.sh [--purge] (--purge also removes the state directory and reports).

Full details, including where the tools keep their state: installation documentation.
