Build and install

Requirements: Go 1.21 or newer, Linux, and for shaping iproute2, iptables and iputils. No third-party Go modules.

command
git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
./build.sh          # builds seven binaries, runs go vet + go test ./...
sudo ./install.sh   # installs to /usr/local/bin + safety docs

Update with git pull && sudo ./install.sh. The installer reads the version from the freshly built binaries and aborts if they disagree. Uninstall with sudo ./uninstall.sh [--purge]; --purge also removes state and reports. Full details in installation.

GNULTE

GNU LAN Network Testing Environment. Seven single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
