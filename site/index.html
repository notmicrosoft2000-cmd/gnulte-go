GNULTE

GNU LAN Network Testing Environment

A suite of eight focused Linux tools for measuring how devices behave when their network misbehaves — latency, jitter, loss, duplication, reordering and bandwidth limits — on networks you own or are explicitly authorised to test.

Install GNULTE Get the source

Scan the LAN, shape a target's traffic with real kernel tc netem (latency, jitter, loss, duplication, reordering, bandwidth), watch every device live, and hand off from one tool to the next — the whole toolkit shares one live view of your network. Everything is written in pure Go against the standard library: since v16.6 no arping, arp-scan, tcpdump or ping is required anywhere (the Unplugged programme).

GNULTE performs ARP-based man-in-the-middle routing, kernel-level traffic impairment, packet capture, LAN discovery and 802.11 injection. Only use these tools on networks, systems and devices you own or are explicitly authorised to test. See authorised use.

Install

GNULTE builds from source with the Go toolchain. You need Go 1.21+ and, for shaping, iproute2 and iptables.

  1. Get the source 
    git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git
cd gnulte-go
  2. Build and install. build.sh refuses to emit binaries that fail go vet or go test ./.... 
    ./build.sh
sudo ./install.sh
  3. Check the machine before your first run. 
    gnulte-doctor

There is nothing else to fetch: no arping, arp-scan, tcpdump or ping is required. The installation guide covers requirements, updating and uninstalling.

First run

sudo gnulte                                            # guided menu: target -> conditions -> run
sudo gnulte -t 192.168.1.50 -l 300 -j 30 --duration 90 # 300ms latency + 30ms jitter, 90s auto-stop
gnulte-lan                                             # six-screen live watch (auto-discovers subnet)
gnulte-scan --deep                                     # sweep + in-Go port scan + OS fingerprint

The tools

BinaryRootWhat it doesDocs
gnulte yes Interactive shaping engine — ARP-spoofed routing into tc netem, live dashboard, live tc -s qdisc telemetry, HTML report. reference
gnulte-lan optional Live LAN watch with a six-screen console — hosts, talkers, flows, ARP neighbours, the live interconnection map, and session history. reference
gnulte-scan optional Parallel sweep plus an in-Go deep port scanner — OUI vendor, mDNS names, OS fingerprinting, -T tabbed browser, live re-scanning. reference
gnulte-devices no Instant ARP/neighbour inventory — vendors, mDNS hostnames, type guesses, HTML reports. reference
gnulte-wifi yes Targeted 802.11 deauthentication for authorised Wi-Fi disassociation testing — per-frame jitter, rotating reason codes, channel hopping. reference
gnulte-doctor no Pre-flight health check — privileges, tc/iptables, ip_forward, kernel modules, routes, duplicate IPs. PASS/WARN/FAIL with fix-it hints; non-zero exit on any failure. reference
gnulte-trace yes mtr-style hop-by-hop path probe — in-process ICMP echo at every TTL, per-hop last/avg/best/worst and loss, --json, HTML report. reference
gnulte-top yes Live per-host and per-conversation bandwidth — an in-process AF_PACKET counter ranked into a top-talker table; --flows, --csv, --json. reference
