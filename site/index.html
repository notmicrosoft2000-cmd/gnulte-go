GNULTE

Eight Linux tools to shape, watch and inspect traffic on a network you own or are explicitly authorised to test. The tools share one device store, so a scan becomes a target list and a live watch becomes a baseline.

one shaped host, 90 seconds
sudo gnulte -t 192.168.1.50 -l 300 -j 30 --duration 90

The suite

01gnulte-scan --deepFind what is on the subnet: hosts, ports, vendors, names.
02gnulte-lanWatch it live. x saves the inventory to the shared store.
03gnulte -t <ip>Shape one host; ⏎ in the watch hands the target over.
04gnulte-topMeasure what the shaping did to throughput.
05gnulte-doctorVerify the machine before and after the run.

Each binary does one job. Discovery feeds observation, observation hands off to shaping, and the measuring tools record what changed. All eight read and write ~/.config/gnulte-go/devices.json.

BinaryRootWhat it doesManual
gnulterootTraffic shaping: latency, jitter, loss, duplication, reordering and bandwidth caps through tc netem, with ARP-redirected routing, a live dashboard and an HTML report.gnulte(8)
gnulte-lanoptionalLive LAN watch: six screens of hosts, talkers, flows, ARP neighbours, interconnection map and session history. Passive counting; nothing is shaped.gnulte-lan(8)
gnulte-scanoptionalParallel ARP/ICMP sweep plus an in-Go TCP port scanner, OUI vendors, mDNS/NetBIOS names, OS fingerprinting, --watch and a tabbed browser.gnulte-scan(8)
gnulte-devicesuserInstant inventory from the kernel ARP/neighbour table: vendors, mDNS hostnames and type guesses. CSV, JSON, YAML or HTML. No root.gnulte-devices(8)
gnulte-wifirootTargeted 802.11 deauthentication from monitor mode for authorised disassociation testing: per-frame jitter, rotating reason codes, channel hopping.gnulte-wifi(8)
gnulte-doctoruserPre-flight check: privileges, tc/iptables, ip_forward, netem/netfilter modules, route, duplicate IPs and the safety record. PASS/WARN/FAIL, --json, exit code.gnulte-doctor(8)
gnulte-tracerootmtr-style hop-by-hop probe: in-process ICMP echo at every TTL with per-hop last/avg/best/worst and loss. No traceroute(8).gnulte-trace(8)
gnulte-toprootLive per-host and per-conversation bandwidth from an in-process AF_PACKET counter, ranked with rates, peers and bars. CSV/JSON snapshots.gnulte-top(8)
02 /

Unplugged

The shell-outs are gone. Since v16.6 each helper has been replaced with in-process code, shipped as an independent increment. tc and iptables remain because they are the kernel interface.

Helper binaryReplaced bySince
arping / arp-scanin-Go ARP who-has frames over AF_PACKETv16.6
pingin-process raw IPPROTO_ICMP echov16.7
tcpdumpin-process AF_PACKET capture writing pcapv16.8
traceroute(8)in-Go per-TTL ICMP probe in gnulte-tracev16.10

Before you run it

Authorised use onlyGNULTE redirects ARP traffic, impairs kernel queues, captures packets and injects 802.11 frames. Use it only on networks, systems and devices you own or are explicitly authorised to test. Read the policy or run gnulte --docs.

GNULTE

GNU LAN Network Testing Environment. Eight single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
