Release log

Milestones from the development of the Go edition. Release announcements are also published in the Atom feed and on the commit log.

01 /

v16.13: watch history and a machine feed

2026-10-03

The LAN watch now remembers. A pure-Go timeline keeps a JSONL record of every debounced up/down transition under the config directory; each finished session files a per-host health snapshot.

Continuous timeline
Every host transition written under the user config directory.
Machine-readable feed
--json turns the console into a JSON-lines stream; narrative goes to stderr.
Trend reporting
HTML reports gain a 7-day RTT chart and a plain 0–100 health score per host.

Technical release notes

02 /

v16.12: scripted scenarios and MOS

2026-10-03

--scenario FILE plays timed impairment phases with sine or sawtooth delay wobble and burst loss, for VoIP, WebRTC and streaming resilience work. At the end of a run the engine rolls up min/avg/p95/max, a loss run-length distribution and a rough E-model MOS.

Notices

Responsible testingThe tools generate deliberate layer-2 redirection and 802.11 management frames. Unauthorised ARP redirection or Wi-Fi injection is a serious violation. Authorised-use policy.

GNULTE

GNU LAN Network Testing Environment. Eight single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
