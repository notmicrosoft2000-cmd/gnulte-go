GNULTE/Suite
SUITE ARCHITECTURE

Where it sits

Eight single-purpose binaries sharing one device store, working at the Linux network queue layer rather than terminating application traffic.

01 /

Problems the suite is built for

Automated resilience testing

Simulate mobile jitter, satellite latency and packet loss in CI matrices. --scenario plays timed phases with delay wobble and burst loss; the session summary reports min/avg/p95/max and an E-model MOS.

Link verification

Observe hop-by-hop latency with gnulte-trace and rank talkers down to individual flows with gnulte-top, without external traceroute or tcpdump.

Embedded device behaviour

Put controllers and gateways behind a shaped link, then watch DNS timeouts, dropped keepalives and delayed firmware payloads in gnulte-lan’s map and 7-day trend.

Authorised LAN auditing

Passive inventory with gnulte-devices, layer-2 isolation checks, and Wi-Fi client reconnect testing with gnulte-wifi. -S keeps spoofing discreet.

Module breakdown

01

gnulte

Traffic shaping: latency, jitter, loss, duplication, reordering and bandwidth caps through tc netem, with ARP-redirected routing, a live dashboard and an HTML report.
reference →
02

gnulte-lan

Live LAN watch: six screens of hosts, talkers, flows, ARP neighbours, interconnection map and session history. Passive counting; nothing is shaped.
reference →
03

gnulte-scan

Parallel ARP/ICMP sweep plus an in-Go TCP port scanner, OUI vendors, mDNS/NetBIOS names, OS fingerprinting, --watch and a tabbed browser.
reference →
04

gnulte-devices

Instant inventory from the kernel ARP/neighbour table: vendors, mDNS hostnames and type guesses. CSV, JSON, YAML or HTML. No root.
reference →
05

gnulte-wifi

Targeted 802.11 deauthentication from monitor mode for authorised disassociation testing: per-frame jitter, rotating reason codes, channel hopping.
reference →
06

gnulte-doctor

Pre-flight check: privileges, tc/iptables, ip_forward, netem/netfilter modules, route, duplicate IPs and the safety record. PASS/WARN/FAIL, --json, exit code.
reference →
07

gnulte-trace

mtr-style hop-by-hop probe: in-process ICMP echo at every TTL with per-hop last/avg/best/worst and loss. No traceroute(8).
reference →
08

gnulte-top

Live per-host and per-conversation bandwidth from an in-process AF_PACKET counter, ranked with rates, peers and bars. CSV/JSON snapshots.
reference →

GNULTE

GNU LAN Network Testing Environment. Eight single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
