GNULTE/Tools
TOOL DIRECTORY · v17.0

Eight executables, one job each

A plain-language launcher, seven focused tools and two subcommands inside the watch. Privilege is requested only when the kernel operation needs it.

01 /

What ships

ExecutableRootPurposeManual
gnulte-hubuserPlain-language menu. Finds the other tools beside itself or on PATH and runs them in the current terminal. Does no network work itself.reference
gnulterootTraffic shaping: latency, jitter, loss, duplication, reordering and bandwidth caps through tc netem, with ARP-redirected routing and an HTML report.reference
gnulte-watchoptionalSix-screen live LAN watch: hosts, talkers, flows, ARP neighbours, interconnection map and session history. Includes trace and top subcommands.reference
gnulte-scanoptionalParallel ARP/ICMP sweep, in-Go TCP port scan, banners, OUI vendors, mDNS/NetBIOS names, OS guesses and live re-scanning.reference
gnulte-inventoryuserInstant inventory from the kernel neighbour table, with vendors, hostnames and type guesses. CSV, JSON, YAML or HTML. No root.reference
gnulte-wifiroot802.11 disassociation testing from monitor mode: named reason codes, station lists, per-frame jitter counters, channel dwell and hopping.reference
gnulte-quicksumuserPre-flight check: privileges, tc/iptables, ip_forward, modules, route, duplicate IPs and the safety record. PASS/WARN/FAIL and --json.reference
gnulte-reportuserReport desk: list and index saved reports, merge device exports, diff two snapshots and file them into dated folders.reference

Watch subcommands: gnulte-watch trace (per-hop ICMP path) and gnulte-watch top (per-host and per-conversation bandwidth).

02 /

A normal run

01gnulte-hubOpen the menu, or call the tools directly from a shell.
02gnulte-quicksumCheck the machine before changing anything.
03gnulte-scan --deepFind hosts, ports, vendors and names on the authorised subnet.
04gnulte-watchObserve the baseline. x saves the inventory to the shared store.
05gnulte -t <ip>Shape one target. ⏎ in the watch hands the target over.
06gnulte-watch topMeasure throughput while the impairment is active.
07gnulte-reportIndex, merge and archive the run's exports.

See usage recipes for worked commands and the manual for every flag.

GNULTE

GNU LAN Network Testing Environment. Eight Linux executables, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
