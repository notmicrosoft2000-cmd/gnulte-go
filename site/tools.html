GNULTE/Tools
TOOL DIRECTORY · v16.13

Eight binaries

One job per tool. Without privileges a tool either degrades gracefully (optional) or cannot run at all (yes). Every tool reads and writes the shared device store.

01 /

What ships

BinaryRootPurposeManual
gnulterootTraffic shaping: latency, jitter, loss, duplication, reordering and bandwidth caps through tc netem, with ARP-redirected routing, a live dashboard and an HTML report.reference
gnulte-lanoptionalLive LAN watch: six screens of hosts, talkers, flows, ARP neighbours, interconnection map and session history. Passive counting; nothing is shaped.reference
gnulte-scanoptionalParallel ARP/ICMP sweep plus an in-Go TCP port scanner, OUI vendors, mDNS/NetBIOS names, OS fingerprinting, --watch and a tabbed browser.reference
gnulte-devicesuserInstant inventory from the kernel ARP/neighbour table: vendors, mDNS hostnames and type guesses. CSV, JSON, YAML or HTML. No root.reference
gnulte-wifirootTargeted 802.11 deauthentication from monitor mode for authorised disassociation testing: per-frame jitter, rotating reason codes, channel hopping.reference
gnulte-doctoruserPre-flight check: privileges, tc/iptables, ip_forward, netem/netfilter modules, route, duplicate IPs and the safety record. PASS/WARN/FAIL, --json, exit code.reference
gnulte-tracerootmtr-style hop-by-hop probe: in-process ICMP echo at every TTL with per-hop last/avg/best/worst and loss. No traceroute(8).reference
gnulte-toprootLive per-host and per-conversation bandwidth from an in-process AF_PACKET counter, ranked with rates, peers and bars. CSV/JSON snapshots.reference
02 /

How they fit together

A typical run moves through the suite in one direction:

01gnulte-scan --deepFind what is on the subnet: hosts, ports, vendors, names.
02gnulte-lanWatch it live. x saves the inventory to the shared store.
03gnulte -t <ip>Shape one host; ⏎ in the watch hands the target over.
04gnulte-topMeasure what the shaping did to throughput.
05gnulte-doctorVerify the machine before and after the run.

See usage recipes for worked commands and the manual for every flag.

GNULTE

GNU LAN Network Testing Environment. Eight single-purpose Linux tools, standard library only, GPL-3.0-or-later.

Maintained by Neptune Productions. Built on tc/netem, netfilter, AF_PACKET and mac80211.
